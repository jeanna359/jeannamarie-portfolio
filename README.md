# jeannamarie.exe — portfolio starter

A simple, responsive, pastel Y2K / desktop-inspired portfolio. **No dependencies or build step.**

## Files
- `index.html` — page layout
- `styles.css` — colors, layout, and responsive styling
- `script.js` — folder/window interactions and portfolio content

## Before sharing the link
1. Open `script.js` and replace `PROFILE.github` and `PROFILE.linkedin` with your actual profile URLs.
2. If you want a résumé link, copy your PDF into this folder as `resume.pdf` and change `PROFILE.resume` to `'resume.pdf'`.
3. Optionally add your email to `PROFILE.email`.
4. Review all descriptions to ensure they accurately represent your work.
5. Double-click `index.html` to preview locally. Test the links on mobile too.

## Publish with GitHub Pages (no other account needed)
1. Create a **public** GitHub repository.
2. Upload `index.html`, `styles.css`, and `script.js` **to the repository root** (not inside a nested folder).
3. Go to **Settings → Pages → Build and deployment**.
4. Set **Source: Deploy from a branch**, choose **main** and **/(root)**, then save.
5. Wait for the site to publish. GitHub will show the exact public URL in the Pages settings.
6. Open the URL in an incognito/private window and test every folder.

## Or publish with Vercel
1. Push these files to a GitHub repository.
2. At https://vercel.com/new, import the repository.
3. For a plain HTML/CSS/JS site, choose **Other** if needed and leave the build command blank.
4. Deploy, then use the exact `*.vercel.app` URL shown in your dashboard.

## Updating later
Edit your files and commit/push the changes. GitHub Pages and Vercel can redeploy while keeping the same public URL. You can later replace this starter with React if you wish.

## Note
The GitHub and LinkedIn links are placeholders until you edit `script.js`. The résumé link stays hidden until you configure it. SceneSense is explicitly labeled *In development*.
