# jeannamarie.exe — updated portfolio

Deploy these files together in the root of your Vercel-connected repository: `index.html`, `script.js`, `styles.css`, `resume.pdf`.

## Before publishing
- Edit `PROFILE.github` and `PROFILE.linkedin` in `script.js` with your real URLs. Placeholder links are automatically hidden.
- Review the Scene Analyzer technology stack and description to ensure it reflects work actually underway; update as the project progresses.
- Review all job descriptions for NDA compliance. This version does not claim internal deployment to Lear technicians.
- Confirm whether the Computer Engineering minor should be listed (currently omitted to match the latest resume).
- Open the site and test the Resume PDF button and all desktop folders on desktop and mobile.

## Vercel
Commit and push these files to the repository connected to Vercel. For a static site no build step is required. If you deployed manually instead, upload the folder contents together. This ZIP does not modify your live site automatically.
